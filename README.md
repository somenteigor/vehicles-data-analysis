# Análise de anúncios de veículos

## Descrição do projeto

Este projeto consiste em uma aplicação web desenvolvida com Python, Pandas, Plotly Express e Streamlit para explorar dados de anúncios de veículos.

## Funcionalidades

- Visualização de um histograma da quilometragem dos veículos.
- Visualização de um gráfico de dispersão que relaciona a quilometragem ao preço dos veículos.
- Exibição de gráficos interativos a partir de botões na interface web.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit
